      How to get Google Client ID & Secret
      
        
      
      
      
      
        
        
          
      1. 
            1. Open Google Cloud Console
            
        Go to Google Cloud Console → Credentials and sign in with your Google account.
        
          
        2. 
          
      2. 
            2. Create a Project
            
        Click the project dropdown at the top bar and select New Project. Name it (e.g. My Nimbus Drive) and click Create.
        
          
        3. 
          
      3. 
            3. Configure OAuth Consent Screen
            
        In the left navigation menu, click OAuth consent screen. Choose External, fill in your App name and user support email, then click Save and Continue.
        
          
        4. 
          
      4. 
            4. Create OAuth 2.0 Credentials
            
        Click Credentials → Create Credentials → OAuth client ID. Choose Application type: Web application.
        
          
        5. 
          
      5. 
            5. Add Authorized Redirect URI
            
        Under Authorized redirect URIs, click Add URI and paste your callback URI:
        
            
        
          
        6. 
          
      6. 
            6. Copy Keys into Nimbus
            
        Click Create. Copy the generated Client ID and Client Secret into Nimbus Desktop and click Save!
